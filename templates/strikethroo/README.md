# Strikethroo

This directory contains AI-assisted task management files for this project.

Managed by the [Strikethroo](https://www.github.com/e0ipso/strikethroo) project.

A `profile` field in `.init-metadata.json` means this workspace's `config/` was seeded from the strikethroo profile it names (source and import date recorded alongside).

**Documentation**: https://strikethroo.canpicasoft.com
